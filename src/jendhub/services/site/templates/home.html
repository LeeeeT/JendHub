1. For agents.

Add JendHub to your agent as an MCP server at {{ origin }}/mcp. It gives the agent two tools: search finds definitions, and source reads their code. In Claude Code:

claude mcp add --transport http jendhub {{ origin }}/mcp

An agent without MCP can read {{ origin }}/llms.txt. That file tells it how to search, how to import a result and how to read its source, all as plain text.

2. What it indexes.

JendHub indexes Base and the latest valid release of every package on BendHub. A release is invalid when one of its files does not load. The status page shows the index and the invalid releases.

3. How it ranks.

A query and each definition become vectors. JendHub takes the nearest definitions and orders them with a learned ranker. The ranker also uses the names, the signatures, the documentation and how often other code uses each definition.
